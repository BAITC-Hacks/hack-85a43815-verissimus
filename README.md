# ⚡ EnergyAI — Мультиагентная система прогнозирования выработки ВЭС

> Проект разработан в рамках хакатона HackAlem AI (Трек: Энергетика / Кейс: АО «Самрук-Қазына»).

## 📌 Описание решения
Автономная Agentic AI-система для почасового прогнозирования генерации ветроэлектростанций (ВЭС) на горизонте 24–48 часов в Шелекском ветровом коридоре (Алматинская область, п. Нурлы).

### ⚙️ Архитектурные особенности:
1. **Agentic AI Orchestrator (OpenAI Function Calling):** LLM-диспетчер принимает запросы на естественном языке, автономно вызывает расчетные инструменты и генерирует экспертные аудиторские отчеты.
2. **Внешняя интеграция (Open-Meteo API):** Сбор архивных метеопрогнозов (скорость ветра на 10м и 100м, температура) строго по географическим координатам ветроустановок (43.643°N, 78.538°E).
3. **Физический Feature Engineering (Закон Беца):** Моделирование нелинейной зависимости мощности от кубической скорости ветра ($P \sim v^3$).
4. **Машинное обучение (LightGBM):** Обучение на исторических SCADA-данных за период с 2023 по 2026 год с защитой от лика данных.
5. **Диспетчерский мониторинг рисков:** Автоматическое выявление часов штиля ($<5\%$ мощности) и выработка рекомендаций по резервированию мощности.

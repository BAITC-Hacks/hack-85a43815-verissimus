# Проверка метода калибровки на декабре 2025 года

Дополнительный ретроспективный эксперимент: **метод ранее выбран на январе**, а здесь проверяется на более раннем месяце. Это проверка устойчивости подхода, не независимое перспективное испытание и не оценка точности февраля. Февральский CSV и установленная январская калибровка не изменялись.

## Фиксированный протокол

- Метод: отдельная линейная поправка для каждой турбины и горизонтов 1–24 / 25–48 часов, ridge λ=24, наклон [0,2], результат [0,1]. Новые методы и параметры по результатам декабря не подбирались.
- Подгонка поправок: даты начала прогнозов 1–16 декабря; 48 часов, кроме 16 декабря (24 часа). Использованы только измеренные целевые часы, завершившиеся к 16 декабря 23:00 `Asia/Almaty`.
- Проверка: даты начала 17–23 декабря, по 48 часов, обе турбины. Итого **672 прогнозные строки**, фактические значения присутствуют во всех 672 строках. Перекрывающиеся прогнозные окна не независимы.
- Декабрьские коэффициенты сохранены до расчёта оценочного окна. Январские коэффициенты в эксперименте отключены.
- Исходные выпуски NOAA GFS и все метки Last-Modified проверены относительно исторического момента решения. Последние завершённые часы SCADA использованы для модели и базовых прогнозов; задержка поступления SCADA сверх окончания часа не моделируется.

## Проверка и воспроизведение

Из корня репозитория после установки зависимостей. `python` означает интерпретатор виртуального окружения; в Windows без активации замените его на `.\.venv\Scripts\python.exe`.

Проверить сохранённые данные без сети и исходных CSV:

```text
python scripts/verify_december_robustness.py --output validation/december_robustness
```

Ожидается `status: passed`, `run_count: 46`, `evaluation_rows: 672`. Проверяются коэффициенты, метрики, контрольные суммы, все ожидаемые часы и ограничения времени. Это проверка согласованности сохранённых свидетельств.

Повторить эксперимент с CSV организаторов и архивом NOAA (каталог результата должен быть новым или пустым):

```text
python scripts/december_robustness.py --output artifacts/december_reproduction
python scripts/verify_december_robustness.py --output artifacts/december_reproduction
```

На проверенном компьютере полный эксперимент занял около 10 минут 34 секунд. Скрипт ограничен 1150 секундами; при превышении или ошибке сохраняется неполный статус. Производственные коэффициенты не перезаписываются. Воспроизводимость численных значений зависит от тех же исходных CSV, версии кода, зависимостей и погодного архива.

## Сохранённые материалы

`protocol.json` фиксирует метод до расчётов. `fitted_before_evaluation.json` содержит коэффициенты и SHA-256 обучающих пар. `training_predictions.csv` содержит 1484 прогнозные строки, из которых 1456 имеют полные фактические значения. `evaluation_predictions.csv` содержит все 672 строки проверки. `report.json` хранит точные метрики и покрытие. `provenance.json` и `raw/` связывают 46 запусков с источниками погоды и исходными прогнозами. `verification.json` содержит итог арифметической проверки.

Время записи артефактов служит локальным свидетельством порядка выполнения, а не независимым заверением. Last-Modified — свидетельство архива, не журнал первой публикации. Часовой пояс исходных данных остаётся допущением; мощность — в исходной безразмерной шкале. Фактической февральской мощности в предоставленных CSV нет.
